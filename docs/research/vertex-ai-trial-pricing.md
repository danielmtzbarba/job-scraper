# Vertex AI Gemini: trial, pricing, and Germany location

Checked 2026-10-04 against Google Cloud's published documentation. Prices are USD list prices per **million** tokens for online Standard PayGo, text input and text output including reasoning tokens. They are estimates for a future test; the project's billing account, credits, and available quota still need to be verified.

## Trial credit

- Google's $300 Welcome credit lasts 90 days for an eligible new Free Trial account and applies to covered Google Cloud services. Google explicitly markets it for generative AI and excludes the **Gemini API in AI Studio** and managed third-party generative AI models. Google-hosted Gemini through Vertex AI/Agent Platform is therefore a covered use of the trial credit, subject to the account actually having an unexpired balance. Do not confuse Vertex AI calls with AI Studio Gemini API calls. [Free Program](https://docs.cloud.google.com/free/docs/free-cloud-features), [Agent Platform product page](https://cloud.google.com/products/gemini-enterprise-agent-platform).
- Eligibility is for users who have not previously been a paying Google Cloud, Google Maps Platform, or Firebase customer and have not previously signed up for the Free Trial. The trial account is not billed beyond its credit; it stops at $300 spent or 90 days. If manually upgraded to paid, remaining credit continues only until the original 90-day deadline; overages and noncovered products can then charge the payment method. [Free Trial FAQ](https://cloud.google.com/signup-faqs), [Free Program](https://docs.cloud.google.com/free/docs/free-cloud-features).
- A free-trial account cannot request quota increases. Verify the actual billing account status, remaining credit, expiration, and quota before assuming this repo is covered. [Free Program](https://docs.cloud.google.com/free/docs/free-cloud-features).

## Current models and locations

| Model | Endpoint suitable for a low-volume test | Input / 1M | Output / 1M | Notes |
| --- | --- | ---: | ---: | --- |
| `gemini-3.1-flash-lite` | `eu` multi-region | $0.275 | $1.65 | Low-cost classification candidate. No Frankfurt single-region endpoint is listed. |
| `gemini-3.5-flash-lite` | `eu` multi-region | $0.33 | $2.75 | Newer classifier candidate. Google describes minimal thinking as suitable for classification and JSON extraction. No Frankfurt single-region endpoint is listed. |
| `gemini-3.5-flash` | `eu` multi-region | $1.65 | $9.90 | More capable scoring candidate. Model availability includes Frankfurt, but its **Standard PayGo** list specifies only `global`, `us`, and `eu`; a straightforward pay-as-you-go test should use `eu`. |

These are **non-global Standard PayGo** rates from [Agent Platform pricing](https://cloud.google.com/gemini-enterprise-agent-platform/generative-ai/pricing), using each model's [3.1 Flash-Lite](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/gemini/3-1-flash-lite), [3.5 Flash-Lite](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/gemini/3-5-flash-lite), and [3.5 Flash](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/gemini/3-5-flash) location page. Gemini 2.5 Flash and 2.5 Flash-Lite retire on **2026-10-20**, so avoid selecting them for this new setup. [Model lifecycle](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/model-versions).

The `eu` multi-region endpoint confines ML processing to EU member states; it does **not** mean processing specifically in Germany. Google documents using `genai.Client(enterprise=True, project=..., location="eu")` for this endpoint. Its global endpoint does not satisfy data residency needs. If the requirement means **Germany-only model processing**, the pay-as-you-go model/endpoint choice needs separate validation before live calls; `europe-west3` as the eventual **app hosting** region does not itself force Gemini processing into Frankfurt. [Endpoints](https://docs.cloud.google.com/gemini-enterprise-agent-platform/resources/locations), [Data residency](https://docs.cloud.google.com/gemini-enterprise-agent-platform/resources/data-residency).

For a rough 10-job run with two requests per matched job, assuming 2,000 input and 300 output tokens per request, `gemini-3.1-flash-lite` at EU rates is about **$0.0209** for 20 requests. Real prompts and reasoning tokens may differ; actual SDK usage and Cloud Billing are authoritative. This estimate excludes any later hosting, storage, collection, and network charges. Price equation: `(input_tokens × input_rate + output_and_reasoning_tokens × output_rate) / 1,000,000`. [Pricing](https://cloud.google.com/gemini-enterprise-agent-platform/generative-ai/pricing).

## Cost control and test prerequisites

- Create a project-scoped monthly budget (for the previously discussed $10/month target) and alerts at sensible thresholds. **Alerts do not cap spending**; Cloud Billing also has reporting delays. A spend-cap budget exists in preview and can be evaluated separately. [Budgets](https://docs.cloud.google.com/billing/docs/how-to/budgets), [Spend caps](https://docs.cloud.google.com/billing/docs/how-to/budgets-spend-caps), [Billing delay](https://docs.cloud.google.com/billing/docs/how-to/resolve-issues).
- A Vertex AI test needs a project with billing, `aiplatform.googleapis.com` enabled, Application Default Credentials (`gcloud auth application-default login`) for the local Python worker, and sufficient permissions (Vertex AI User for inference; Service Usage Admin or equivalent to enable the API). `gcloud auth login` alone does not establish ADC. [Vertex AI Gemini quickstart](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/start/quickstart).
- Before creating anything, confirm the **specific GCP project ID and billing account/credit state** in the user's authenticated terminal. The user's request authorizes setup, but a logged-in `gcloud` default does not identify the intended project. Use `europe-west3` for a future Germany-hosted app if Germany is the desired hosting region, and `eu` for the initial low-volume Gemini inference test unless the user requires German-only model processing. [Endpoints](https://docs.cloud.google.com/gemini-enterprise-agent-platform/resources/locations).
