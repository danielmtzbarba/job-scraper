## Purpose

Build an agent-assisted job scraping and tracking application on Google Cloud using Vertex AI and Gemini, with Python and `uv`. The intended system has an MCP server, Apify collection, and Cloud SQL PostgreSQL for hosted job tracking; SQLite remains the local debugging store. Airtable was the original tracker and is being retired after its trial limit was reached.

This is the evolving implementation brief. Brainstorming is complete; the user has authorized a local-first start before cloud deployment.

## Current architecture

See `docs/architecture.md` for the selected flow, deployment boundary, open prerequisites, and GCP resource inventory. The earlier Apify → Airtable conceptual flow was superseded by the local BA collector and the SQLite/Cloud SQL storage choice.

### Confirmed CV matching approach

- Derive a compact, standardized career profile from a CV variant and/or canonical candidate dossier (skills/proficiency, roles, dates, projects, accomplishments, and evidence snippets). Have the user review/correct the resulting profile. Only that profile is supplied to the JD scorer; CVs and dossier records are upstream source material.
- Score explicit stack overlap against the standardized profile, with Python carrying the greatest skill weight. Separately assess semantic similarity and adjacent experience using relevant experience evidence embedded in that same profile.
- Have Gemini return dimension scores, a combined fit score/category, and a concise explanation grounded in specific evidence contained in the selected profile. Sort primarily by fit; use recency second.
- Start with a small profile that contains the evidence needed for both dimensions rather than committing to a managed vector database. Reassess profile size and selection if the source material grows enough to justify it.
- Benefits: a consistent, compact scoring input that retains enough evidence and nuance for adjacent-experience matches. Risks: profile compilation can omit nuance or introduce errors, so keep provenance and user review in the upstream build process.
